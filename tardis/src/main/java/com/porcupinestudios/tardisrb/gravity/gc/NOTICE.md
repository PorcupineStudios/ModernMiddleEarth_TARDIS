# Gravity Changer port

The code in this package (except `GravityHolder`, `api/GravityChangerAPI` and `mixin/EntityGravityDataMixin`, which
are ours) is ported from Gravity Changer for Minecraft 1.21.1
(https://github.com/NightEpiphany/gravity-changer-1.21.1, CC0 1.0), itself based on qouteall's Gravity Changer
(https://github.com/qouteall/GravityChanger, MIT, Copyright (c) 2021 Gaider10). Changes: package names, the Cardinal
Components gravity component replaced by a plain entity field, config flags fixed to their defaults, the item-throw
and debug mixins left out.
