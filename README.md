# Archive: Claude project shared files (2026-11-04)

Snapshot of the old Claude project's shared folder (`/mnt/project-files/`), saved when Aaron moved to a new Claude
account. This branch is never merged into main, so clones of main stay small.

- `tardis-interior/`: Capaldi interior exports (full, light, blocky, hand-built Minecraft style) and Aaron's review.
  `capaldi_minecraft/` is the one used in `tardis_rb`. Built from a model Aaron bought (liamjmwilson): keep private.
- `builds/`, `jars/`, `test-build/`: old mod jars (rebuildable from git; CI's `test-build` release has the latest).
- `screens/`, `gravity/`: screenshots from space and gravity testing.
- `uploads/hearth/`: files Aaron uploaded in the project chat (extensions added by file type).
