The main line

Six phases. Each one ends with something you can play on the server, so if a later phase stalls, the earlier ones are still finished features. Phases 2 to 4 finish the existing time-travel implementation plan; 5 and 6 go past it.

P1

Land and stabilise

S–M · about 1–2 weeks

Everything already built is merged, the server runs one jar, and the paradox work in progress is finished.

  • Merge the stack in order: #1 → #2 → #3 → #4 → #5 → #6 → #8, and #7. Rebase each on the one before as it lands so main never holds half a feature.
  • Review and playtest the paradox system (PR #8): duplicate and contradiction detection, scaling penalties, config for everything, and the safe-travel hooks Observer Mode will use.
  • Fix the known bug: chunks shifted by paradox come back unshifted after a reload.
  • Client check backlog. Several features were only tested on a dev server: roundel cable ends and terminal GUI, soul labels and NEI page, RFTools matrix flight, Create x LOTR textures and saw blade, Upgrade Rack GUI. One sitting in a real client clears all of them.
  • Green CI. Compile against small API stub jars, or keep the Dependencies jars as a private release asset the workflow downloads.
  • A playtest week on the real server with trips.freeTimeTravel on, measuring real recorder disk use per hour.
Done when main has every feature, CI is green, and the server has run a week of normal play with the recorder on and no crash.
P2

Close the time loop

L · about 3–4 weeks

Time travel works for a group: crews, several crews at once, and a safe way to visit.

  • Crews: one TARDIS's travellers share a paradox meter and a past dimension. An offline member keeps the trip open; the others go home when they catch up.
  • Multiple crews: separate out-of-sync past dims, changes applied in order of past moment, and one crew seeing another's TARDIS arrive.
  • Observer Mode (your safe-travel idea): a console switch that blocks every paradoxical action (break, place, containers, attacking, picking up), costs less fuel and adds no paradox. Built on the paradox hooks from P1.
  • Paradox on the console: a needle gauge on a cockpit desk and a HUD meter, with the Strained, Unstable and Fracturing stages live.
  • Dupe gauntlet: a written list of every dupe route we can think of (ores, chests, ME drives, soul nexus, remote trading, waystones, ender chests, kinetic contraptions carrying blocks across time) run before each release.
Needs: P1 merged, paradox hooks
Done when two crews visit the same day, one in Observer Mode, and every item on the dupe gauntlet leaves the duper with nothing.
P3

Fuel economy

L · about 3 weeks

Time travel costs something you make, and the half-life ores give a reason to go exploring.

  • Artron rework: slower natural regeneration, faster flight drain, both as config multipliers.
  • Artron Charger: AE and RF in, artron out, with a big conversion loss.
  • Chronons: Chronon Tank in the TARDIS, refining in the temporal basin (artron + kontron + chronosteel), rift harvesting in an unstable past, and the trip cost formula (base + depth, times crew size, times paradox).
  • Half-life ores, tiers 1 and 2 in the Overworld and Middle-earth. Yield per block decays with world age; ore is drained into a cell and never becomes an item. Crafted items per tier.
  • Fuel grades 1 and 2: Chronon (24 hours back) and Isotope Rod (7 days back).
Needs: P2 crews (cost scales by crew size)
Done when a trip to yesterday costs Chronons refined from your own power setup, and a fresh ore vein reads a higher yield than an old one.
P4

Protection and consequence

L · about 3 weeks

Bases are safe from travellers, mistakes can be undone, and high paradox really hurts.

  • Temporal Anchor (3×3 chunks, share list, protection back to your first build) and the Deep Anchor (back to world start), with visit alerts and the veil.
  • Paradox Machine (5×5 chunks): Restore and Rewrite modes, an archive of the replaced version, Paradox Collapse to undo, and a rewrite cooldown.
  • Collapse in full: escape cost on the console, crew death, item loss by config, exterior lost but resummonable.
  • The 12 time upgrades in the Upgrade Rack (designed in the half-life ores doc), now that fuel and paradox exist for them to change.
Needs: P3 fuel (anchors and machines run on Chronons), #6 Upgrade Rack
Done when a deliberate dupe ends in collapse, an anchor stops a test intruder, and a Paradox Machine restores a blown-up build.
P5

Deep Time

XL · about 4–6 weeks

Travel before the world was created, into land nobody has touched, for the richest fuel.

  • Before-creation trips built from the world seed, with the slower prehistory half-life and a cap for negative time.
  • Fuel grades 3 to 5: Chronal Fuel Cell (to creation), Quantum Fuel (10 days before), Primordial Fuel (100 days before), efficiency 1× to 5×, cost growing with the log of depth.
  • Higher ore tiers (quantum and beyond) that only show their full yield in deep time.
  • Deep-time flavour: no player history, no structures yet, different sky and weather, optional ancient-only creatures.
Needs: P3 ores and fuel, P4 upgrades (depth range)
Done when you land 50 days before the world existed, drain a primordial vein, and fly home on what you mined.
P6

Release and beyond

M + ongoing

The mod is finished enough to hand to other players.

  • Mob ghosts, admin rollback commands, history compaction (20–40% less disk).
  • Sounds, rift and vortex effects, your own TARDIS map icon.
  • An in-game manual book covering every feature, plus a config guide page.
  • Versioned releases with a changelog and the server backup-and-swap routine written down.
Needs: P4 at least; P5 can ship in a later version
Done when someone who has never seen the mod can install it, read the manual and take a trip.

Side branches

These can grow alongside the main line. Each card says what it needs first. Starred cards are the ones I'd pick first in that area: cheap, or tied tightly to time travel.

Time travel extras

extends P2–P5

The recorder already knows who changed every block and when. A lot of fun features fall out of that data cheaply.

Chrono-Cannon

A kinetic machine that rebuilds a destroyed build from history, block by block, using real materials from an inventory. Schematicannon meets the recorder. No paradox, because it only places in the present.

Mneeds P1 + kinetics

Time Capsule

Put items in, set a date, and they unlock that many real days later. Safe by design because it only goes forward.

Sanytime

Letters to the past

A book written in the present appears on a lectern in your crew's past dimension. Information only, so no paradox. Good for puzzles and pranks.

Sneeds P2 crews

Forensic Lens

Look at a block and see who placed or broke it and when. Anti-grief tool, owner-only inside an anchor.

Sneeds recorder

Chrono-Wrench

Undo one block to how it was a few minutes ago, for Chronons. Only inside your own anchor, so it is a convenience, not a weapon.

Sneeds P4 anchors

Time Museum room

A TARDIS room that shows a chosen past moment of a 3×3 chunk area as a holographic diorama (HoloRender + rewind engine). Scrub through the day your base was built.

Mneeds P1

Fixed points

A config list of moments and areas that can never change (spawn, boss kills, server events). Forcing one sends paradox straight to Fracturing.

Sneeds paradox hooks

Paradox storms

At Fracturing, a weather event in the past dim: rifts open, blocks swap, ghosts stutter, the sky tears. Rifts are where you harvest emergency Chronons.

Mneeds P3 rifts

Bootstrap items

Carry an item back and leave it exactly where your past self found it, and it becomes a Bootstrap item: unique, tradeable, no gameplay power, a trophy.

Sneeds P2

A book or desk screen: most-changed chunks, your total build hours, first day you met each player, longest session.

MP6

The wild list

Huge or strange ideas. None of these is planned; they are here so they aren't forgotten.

Chronovore

A boss that spawns in collapsing past dims and feeds on paradox. Kill it before it eats the dimension and it drops a Chronal Heart, a big Chronon store.

Time-loop dungeon

A generated structure that resets every 10 minutes. You keep what you learn, not what you carry. Puzzle rooms that need ten loops of knowledge.

The server's first day

A one-time server event: everyone travels together to tick 0 and watches the world being born. A landmark marks it.

Ages of Arda

Deep time in Middle-earth shows older versions of LOTR structures (ruins whole again, forests wider), built from the seed with LOTR's own generators run at a different "age" setting.

Alignment echoes

Killing faction members in the past costs nothing in the present, unless a member you killed is one you later hired. Then your hired unit vanishes and alignment drops.

Grandfather clause

If you kill your own past ghost-self (impossible today, ghosts are untouchable) the crew collapses instantly. A hard rule spelled out in the manual for flavour.

Temporal weather forecast

A cockpit desk that forecasts paradox storms and rift openings in open past dims, so crews plan their harvesting runs.

Paradox insurance

Pay Chronons before a trip; if the crew collapses, the insured items come home. A real economy around risk.

Speed-run board

Fastest trip to a given past moment and back, lowest paradox for a full past day, longest trip without Observer Mode.

Second TARDIS interior in the past

Visit your own TARDIS interior as it was. Very hard (interiors are excluded from history on purpose) and probably a bad idea, which is why it is on this list.

Suggested next moves

Finish P1. Let the paradox thread finish, merge the PR stack in order, and do one client check session for the backlog.
Start P2 with crews and Observer Mode. They make time travel playable with friends and give the paradox system its first real test.
Pick one quick side win to run alongside: RFTools screen modules (small, uses existing data) or the Time Capsule (small, safe, fun). The Chrono-Cannon is the bigger favourite if you want something flashy.
