What the graph shows

Everything goes through three hubs. TardisMod (78 users), TMRegistry (74) and Helper (58) are static singletons nearly every class reaches into. The port can replace them with a registry and small services instead of one global.

The TARDIS lives in tile entities. CoreTileEntity (1,965 lines), ConsoleTileEntity (1,514) and EngineTileEntity (812) hold flight, energy, rooms, permissions and controls. TardisDataStore holds the per-dimension save. Most cross-area arrows point into these four.

Components are a plug-in seam. ComponentTileEntity plus ITardisComponent / AbstractComponent let blocks on the hull add AE2, RF, IC2, fluid and inventory links. Upgrades and chameleon skins in tileents.extensions follow the same pattern.

darkcore is everywhere. 149 imports come from io.darkcraft (darkcore): base blocks, tile entities, data stores, GUIs and the Sonic screwdriver helpers. Anything ported needs a replacement for each darkcore base class it extends.
