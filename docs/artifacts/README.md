# Artifacts archive

Copies of every claude.ai artifact made for these projects up to 2026-11-08, saved so they survive an account switch.
`docs/` holds the Claude Docs as Markdown exports; `html/` holds the published HTML pages (each `index.html` plus its files).
The original links only open for the account that made them.

Export notes: date and @mention chips became plain text. The Gameplay Guide and Implementation Plan each had one
embedded widget (a roadmap/diagram) that became a text placeholder.

The project's shared files folder (uploads, screenshots, notes) is on the separate, never-merged branch
`archive/project-files`.
